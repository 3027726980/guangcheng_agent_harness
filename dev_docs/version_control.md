# 版本管理约定

- `main` 保存项目基线，不直接开发；功能实现使用 `dev/runtime`。
- 每个完整、可验证的修改批次检查差异后提交。
- 未明确要求推送时，不执行 `git push`，也不通过 API 上传代码或创建远端提交。
- GitHub 创建私有空仓库并关联 `origin`，远端创建与代码推送分别处理。
- 已关联仓库：https://github.com/3027726980/guangcheng_agent_harness 。当前没有推送的代码，远端空仓库不会展示本地实现。
- 数据库、API Key、日志、环境配置、依赖目录与构建产物不提交。
- 主 Agent 独立开发，默认不创建子 Agent。
