## 首版实现中的局部取舍

- 使用少量聚焦模块而不是先铺满规划目录，避免空层次。模块职责仍与路线一致。
- 模型未知 tokenizer 时保守估算；已匹配 tokenizer 的计数仍包含估算开销，不宣称等于供应商账单。
- 对话和摘要请求省略总输出上限，使用供应商默认值；Context 预留和摘要正文长度目标自动计算，后者仅通过提示词引导。连接配置中的输出参数名称用于连接测试，推理强度仍可配置，不静默更换参数／模型。推理 token 和摘要正文不能共用一个很小的硬上限。
- 逻辑取消立即生效，但必须核实在途 SQLite 提交，不能为追求按钮响应而虚构回滚。
- 真实 API 的连接测试与完整工具能力验收分开。
- SQLite JSON 记录结构适用于单进程演示，正式迁移与多实例不在本次范围。
