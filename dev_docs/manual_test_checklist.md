# 界面与真实模型验收清单

日期：2026-10-20。开发实现位于 `dev/runtime`；`main` 仅保留原题与规划基线。

本轮重新执行：后端 50 项测试、前端 8 项测试、Ruff 检查／格式检查、TypeScript 检查及生产构建均通过。后端使用临时数据库和可控模型响应；此前浏览器检查使用模拟 API。下面的勾选项留给实际操作验收，不表示真实模型联调已经完成。

## 测试准备

- [ ] 切换到 `dev/runtime`，安装 README 中的前后端依赖。
- [ ] 运行 `backend/scripts-dev/quick-start/main.bat --check`，检查依赖和 8000／5173 端口。已运行服务会占用端口，此时不要重复启动。
- [ ] 代码更新后先停止旧后端再重新启动，刷新页面；`http://127.0.0.1:8000/docs` 中应能看到删除会话及 `steer-queued` 接口。
- [ ] 用演示用户 A 创建专门的测试会话和待办；测试用数据与日常数据分开。

## 配置与连接

- [ ] **未配置模型**：对话页有提示和设置入口，填写输入后发送按钮仍禁用，Enter 不创建任务。
- [ ] **失败配置**：测试错误地址／模型 ID 的连接，显示失败；选用未通过测试的配置时不能发送。之后恢复有效配置。
- [ ] **有效配置**：填写真实兼容接口并保存，连接测试成功；选为对话模型，保存全局设置。此步骤会真实调用模型。
- [ ] **容量来源**：读取到供应商容量则显示其数值和来源；无元数据时显示默认来源及 `262.1k`（262144 tokens），不能把默认值当供应商保证。千／百万量级分别使用 `k`／`m`。
- [ ] **右上角状态**：后端连通且模型已配置并通过测试时显示“后端已链接”；悬浮能分别看到后端／模型的 ✓ 或 ✕ 及原因。

## 对话、工具与待办

- [ ] **纯对话追问**：发送“记住测试代号蓝鲸”，再问“刚才的测试代号是什么”；当前会话能承接历史。
- [ ] **计算和写入闭环**：发送“计算 128 乘 36，把结果记为待办标题，内容写上计算过程”。检查结果为 4608，实际待办列表有记录，Trace 有成功工具结果。
- [ ] **工具追问**：继续要求查询刚才待办并完成它；ID、版本和完成状态来自实际工具结果。
- [ ] **模拟搜索**：发送“搜索 Python 学习资料”；界面／回答明确说明是 Mock 样例资料，无匹配时不捏造实时搜索结果。
- [ ] **过程顺序**：说明文字、calculator、后续说明、todo、最终回答按原位展示；每次调用分别折叠，展开可见对应参数和结果。同批并发按请求顺序展示。
- [ ] **手动新增待办**：标题必填，内容可选且支持多行；内容里的 Enter 换行而不提交，成功后清空两项输入，列表保留换行。
- [ ] **待办编辑与删除**：内容能回填编辑；完成／取消完成、修改、删除后状态正确。长短标题与完成／未完成复选框、正文、操作按钮对齐。
- [ ] **版本冲突**：两个窗口同时编辑同一待办；较旧版本保存时提示冲突并刷新，不静默覆盖。先打开两个编辑弹窗，再分别保存。

## 队列、引导与停止

- [ ] **普通排队**：让 Agent 执行较长回答，在输出期间再发两条消息；两条显示在队列中，不打断当前任务，之后依次执行。
- [ ] **逐条引导**：点击某条排队消息旁的“引导”；它从独立队列移出并显示“引导待生效”，其他排队消息保留，补充进入当前任务的下一次模型调用。
- [ ] **不重复执行**：已转为引导的消息不会随后再作为独立任务运行，也不显示为取消错误；当前任务预算不重置。
- [ ] **转换时机边界**：当前任务已结束／正在停止时，禁止或拒绝转换，保留原排队消息。重复转换的幂等性也由离线用例覆盖。
- [ ] **手动停止**：模型输出中点击停止，停止后不继续追加回答；已有输出、停止标记及已成功写入的待办保留，下一条普通队列继续。
- [ ] **取消排队**：单独取消一条排队消息，其他排队消息和当前任务不受影响。

## 多窗口与断线

- [ ] **两个独立会话**：用户 A 在两个窗口选择不同会话，分别设置不同测试代号；追问不串聊天，A 的待办在两窗口共享。
- [ ] **活动圆圈**：后台会话执行／排队／停止时，左侧持续转圈；切换会话仍更新，全部任务结束后消失。刷新后以服务端状态恢复。
- [ ] **用户隔离**：切换用户 B，不能看到 A 的会话和待办；再切回 A 可恢复 A 的数据。
- [ ] **断网／关窗**：客户端断开被后端检测后，该客户端当前和排队任务取消；其他窗口任务继续。重连不自动重跑，断线检测可能存在延迟。
- [ ] **提示可关闭**：重连后顶部断线提醒消失；历史取消提示可关闭，在当前窗口刷新、切换后仍收起，链路保留记录；其他业务错误不会被重连误清除。

## Context、链路与删除

- [ ] **圆环**：发送按钮旁显示 Context，用量尚未估算时为“—”；调用后显示估算百分比，点击能看到容量、来源及摘要入口。
- [ ] **摘要开关**：尚未生成摘要的提示可关闭、可重新打开；打开后容量浮层收起，切换会话后摘要区域关闭。
- [ ] **执行链路**：能按任务选择，每页最多 8 个步骤；开始与结果配对，默认折叠，翻页和展开均可用；失败原因和重试次数清晰。
- [ ] **删除空闲会话**：确认后列表移除，删除当前会话会切换或新建；其他窗口同步，共享待办保留。当前使用逻辑删除，底层执行证据保留。
- [ ] **删除忙碌会话**：仍有运行／排队任务时提示先停止，不误删；先停止任务并取消队列后可删除。
- [ ] **窄屏**：约 390px 宽度下，侧栏、队列按钮、内容输入及待办不横向溢出，关键按钮可操作。

## 进阶异常验收（可控环境最后检查）

- [ ] **重试**：离线测试验证 3 次重试及 30 秒默认等待；真实使用遇到 429 时，核对原因、等待时间和次数展示。不要主动高频请求制造限流；可设置重试次数为 0 验证关闭重试。
- [ ] **配置快照与预算**：运行期间改变全局预算，当前任务沿用原快照，新任务采用新配置；有限预算结束显示“达到限制”，不会冒充成功。
- [ ] **实际摘要与追问**：使用容量较小的测试模型或足够长的历史触发压缩；检查摘要保留测试代号、约束和操作状态，压缩后可追问。不要伪改供应商容量来强迫压缩。
- [ ] **重启恢复**：执行和排队期间停止后端再重启，历史／待办／设置保留，遗留任务中断或取消，不自动重放工具；继续任务通过新消息发起。

每次失败记录：用户／会话、模型 ID、输入、期望与实际结果、任务 ID、Trace、是否可重复。记录中不放 API Key。
